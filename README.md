# Sobre o Projeto

O **COGITO** é um sistema de gestão financeira desenvolvido para auxiliar no controle e na organização das finanças empresariais e residenciais. A plataforma permite que o usuário acompanhe receitas, despesas e saldo, oferecendo uma visão clara da situação financeira por meio de extratos mensais e da comparação entre diferentes períodos.

O principal objetivo do sistema é proporcionar uma ferramenta prática e intuitiva para apoiar a tomada de decisões financeiras, contribuindo para uma gestão mais eficiente dos recursos.

---

# Objetivos

- Organizar receitas e despesas de forma centralizada;
- Disponibilizar extratos mensais para acompanhamento financeiro;
- Permitir a comparação do saldo entre diferentes meses;
- Atender tanto usuários residenciais quanto empresariais;
- Facilitar a gestão financeira por meio de uma interface simples e objetiva.

---

# Funcionalidades

- Cadastro e gerenciamento de receitas;
- Cadastro e gerenciamento de despesas;
- Visualização do extrato mensal;
- Comparação do saldo entre meses;
- Controle financeiro para pessoas físicas e empresas.
