# Regras do Projeto COGITO

## Documentação e Comentários no Código
- **Comentários Obrigatórios**: Todo código Dart (`.dart`) criado ou modificado no projeto deve conter comentários detalhados em português (`///` para classes e métodos, `//` para seções e trechos importantes).
- **Explicação de Funções**: Explicar a finalidade de cada classe, método, parâmetro relevante e lógica de negócio ou de interface.
